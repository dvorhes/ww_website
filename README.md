# White Wizzard Website

Static website for White Wizzard.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Files

- `index.html` - page markup
- `styles.css` - site styles
- `script.js` - navigation, form demo states, and hero video poster behavior
- `white_wizzard_media/` - optimized site assets currently used by the page
